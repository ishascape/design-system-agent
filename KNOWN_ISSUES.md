## Found and fixed

- Studio, 2026-11-02, first live run of ashnidave.com (on Ashni's computer): spacing tokens that change at `(width>=600px)` were not read, `--grid-line` and `--shadow-ink` (bare RGB channels) were typed "other", and 7 of 39 custom properties were hidden from review without a reason. Range media queries and RGB channels are now read (channels stay channels in the generated CSS so `rgb(var(--x) / a)` keeps working), and review lists what it left out with a plain reason.
- Studio, 2026-11-02: a Pico CSS run produced a 429-row review table (402 rows were one colour palette). Review now groups numbered scales into families with a keep-all checkbox, and discovery skips `*.min.css` copies.
- Studio, 2026-11-02: website import missed styles that sites build with JavaScript. Websites are now also rendered in a sandboxed browser (no access to this computer or the local network), which captures those styles and a screenshot.
- Studio test, 2026-11-02: the first version of the "page cannot call this computer" test passed even with the block removed, because the test page's address was malformed. Fixed, and shown failing without the block.
