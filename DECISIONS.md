# Decisions

Short log of engineering decisions. Larger ones have an ADR in `docs/adr/`. Product and design decisions are Ashni's and are marked as such.

| #   | Date       | Decision                                                                                                                                                                                                                                | Why                                                                                                                                                |
| --- | ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | 2026-11-02 | Own private repo, separate from every source. Sources are read at a pinned commit.                                                                                                                                                      | Never risk the live site; every audit is reproducible. (ADR 0001)                                                                                  |
| 2   | 2026-11-02 | AI proposes, scripts generate. Audits and specs are validated with zod before writing.                                                                                                                                                  | Repeatable, testable output instead of one-off AI generation. (ADR 0001)                                                                           |
| 3   | 2026-11-02 | One pipeline in one repo with packages, not separate services for each agent capability.                                                                                                                                                | One person plus Claude can maintain it; the brief asks for this.                                                                                   |
| 4   | 2026-11-02 | npm workspaces, strict TypeScript, Node's built-in type stripping for CLIs.                                                                                                                                                             | No build step for tools; fewer moving parts.                                                                                                       |
| 5   | 2026-11-02 | DTCG token format with `$extensions` under `dev.dsa.*` for provenance, responsive, fluid and reduced-motion values.                                                                                                                     | Standard format other tools read; extensions keep what DTCG cannot express yet.                                                                    |
| 6   | 2026-11-02 | Token values come only from the audit inventory; the curated map holds names and descriptions.                                                                                                                                          | Hand-typed values were wrong once; this makes every value traceable.                                                                               |
| 7   | 2026-11-02 | Style Dictionary 5 with two custom formats (CSS and a flat manifest).                                                                                                                                                                   | Maintained, Apache 2.0; the manifest gives Figma, docs and agents one shared input.                                                                |
| 8   | 2026-11-02 | Fluid `clamp()` tokens store the minimum as the static value.                                                                                                                                                                           | Figma variables cannot hold `clamp()`. The minimum matches the mobile base. Code keeps the clamp.                                                  |
| 9   | 2026-11-02 | Storybook 10 for the docs site, with a Playwright check over every story.                                                                                                                                                               | Previews, controls and prop tables for free; the browser check makes interaction and contrast tests real, not assumed.                             |
| 10  | 2026-11-02 | Agent docs are generated: `catalog.json`, per-component Markdown, `llms.txt`, props from the TypeScript checker.                                                                                                                        | Ashni asked for components humans and agents can both read. Generated docs cannot drift from code.                                                 |
| 11  | 2026-11-02 | Figma writes use the official Figma MCP `use_figma` tool, writing only to Ashni's scratch file `wCnc6RXvuK5ZuwanC1epne`.                                                                                                                | Works on the free plan; no token stored in the repo; no write to any original file.                                                                |
| 12  | 2026-11-02 | Every Figma write returns a read-back that is checked against the registry before ids are saved.                                                                                                                                        | Gate 0 showed one binding silently failing. In MVP v1 the check caught two more real bugs (see `KNOWN_ISSUES.md`, fixed).                          |
| 13  | 2026-11-02 | Bound paints carry the token's colour as their raw fallback, and the read-back flags any mismatch.                                                                                                                                      | Figma rendered bound paints with a black fallback. Found by screenshot, then made a permanent check.                                               |
| 14  | 2026-11-02 | Figma variables use one mode named "Value" holding the mobile-base values. Responsive values are written into the variable description.                                                                                                 | Free-plan mode limits are unverified, and Figma has no breakpoint modes. Revisit with themes.                                                      |
| 15  | 2026-11-02 | Disabled Button state: 45% opacity. Not in the source. **Decided by Ashni.**                                                                                                                                                            | The source has no disabled style. Product decision.                                                                                                |
| 16  | 2026-11-02 | The Button does not support being a `<span>` inside a link (as `Work.tsx:70` does in the source).                                                                                                                                       | Nested interactive elements are an accessibility bug; the card should be the link.                                                                 |
| 17  | 2026-11-02 | Style parity and source audit run locally, not in CI.                                                                                                                                                                                   | The source repo is private; CI holds no secrets.                                                                                                   |
| 18  | 2026-11-02 | `npm ci --ignore-scripts` everywhere.                                                                                                                                                                                                   | Install scripts are a supply-chain risk and nothing here needs them (verified with a clean install).                                               |
| 19  | 2026-11-02 | `line.building` is 1px, not the source's 1.5px. **Decided by Ashni.** Recorded as an `override` in the token map; the source value stays in provenance.                                                                                 | Browsers draw 1.5px as 1px on standard screens; 1px matches what people see. Design decisions are explicit and reversible.                         |
| 20  | 2026-11-02 | Token names approved by Ashni (`registry/tokens/ashnidave.token-map.json`, status approved).                                                                                                                                            | Product decision.                                                                                                                                  |
| 21  | 2026-11-02 | The Studio runs on Ashni's computer, bound to 127.0.0.1, with Host and Origin checks. **Decided by Ashni.**                                                                                                                             | No hosting cost, sources and tokens stay local, nothing is public.                                                                                 |
| 22  | 2026-11-02 | Studio storage is Node's built-in SQLite plus a folder per project.                                                                                                                                                                     | No database server to install or pay for, no native modules (we install with `--ignore-scripts`).                                                  |
| 23  | 2026-11-02 | Workflow state lives only in the database; the interface refetches on server events.                                                                                                                                                    | Progress shown is always the real state; a restart loses nothing and marks interrupted steps.                                                      |
| 24  | 2026-11-02 | Unbuilt stages and sources fail as "Not available yet" (`StepBlocked`).                                                                                                                                                                 | Honest about what works; no fake success.                                                                                                          |
| 25  | 2026-11-02 | The canvas lays stages out top to bottom by what each reads; the number shows run order.                                                                                                                                                | Readable at full size beside the inspector, and the edges mean something.                                                                          |
| 26  | 2026-11-02 | Website import downloads HTML and same-origin stylesheets only; imported content is never executed.                                                                                                                                     | Source content is untrusted. Rendering with a browser comes later, sandboxed.                                                                      |
| 27  | 2026-11-02 | Websites are also rendered in headless Chromium: fresh profile, no downloads, permissions or service workers, requests to this computer and the local network blocked. Rendered styles are used when the HTML has none (or when asked). | Many sites build styles with JavaScript. The page's scripts run only inside the browser sandbox; the Studio never runs anything the page produces. |
| 28  | 2026-11-02 | Review groups numbered scales (`--red-50`…`-950`) into one family; families over 12 tokens start collapsed.                                                                                                                             | Real libraries ship full palettes; reviewing them row by row is unworkable.                                                                        |
